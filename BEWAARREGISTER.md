# Handmatig bewaarbeheer — eigenaar Gianluca Scalise

Gebruik voor echte aanvragen een beveiligde administratielocatie, NIET een publieke GitHub-repository. Dit bestand is een leeg sjabloon, geen aangetoond bijgehouden register. Geen klantgegevens ingevuld tijdens de releasecontrole.

| Aanvraag-ID / omgeving | Laatste inhoudelijke contact | Afronding | Uiterste verwijderdatum | Uitzondering + herbeoordeling | Forms/Blobs/uploads/mail/back-ups gecontroleerd | Uitgevoerd op/door | Resultaat / restkopieën |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | |

Voor iedere nieuwe aanvraag een rij toevoegen. Iedere week deadlines controleren, uitvoering uiterlijk op de deadline. Geen namen van kinderen, volledige mails of werkplanteksten opnemen. Verwijder nooit blind financiële registraties. Gebruik LANCERING.md als volledige procedure. Toegang beperken; stel ook voor dit minimale bewijsregister een gemotiveerde bewaartermijn vast.
